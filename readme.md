# Personal Life Manager - Client

React + TypeScript + Material UI frontend for personal diet and finance tracking.

## Environment

Optional `.env` in `client`:

```bash
VITE_API_URL=/api
```

## Scripts

- `npm run dev` - start Vite dev server
- `npm run build` - build production assets
- `npm run preview` - preview production build
- `npm run typecheck` - run TypeScript checks
- `npm run test` - run Vitest tests

## Current sections

- Auth: signup, login, forgot/reset password
- Food: recipes, meal made events, meal consumption tracking
- Finance: payment tracking (amount/date/category/notes)
